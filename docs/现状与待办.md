## 一、这个项目是什么

**YZZ = your zero-config zone** —— 一个 Windows 便携版 AI Agent 启动器。

核心承诺：把一个文件夹放进 U 盘/移动硬盘，插到任意 Windows 机器上双击 `start.cmd`，
Git + Node + 19 种 CLI agent 全部从盘里跑，宿主机什么都不用装；
`USERPROFILE` / `APPDATA` / `TEMP` 全部重定向到盘内；退出时擦掉凭据、保留配置。

- 本地目录：`E:\YZZ`（2026-10-25 由 `E:\PocketAgent` 改名）
- 远程仓库：`git@github.com:Y-Z-Z-BEST/YZZ.git`（private）
- 推送方式：改完跑 `repo-push.cmd`
- 许可证：MIT

## 三、明确的缺口

### 1. `dsh\` 目录是空的 ⬜
README 里写「可选：便携版 DeepSeek Harness 的 App\ 与 data\」，但实际没部署。
`hub\bin\dsh.sh` 的定位链是 `$DSH_BIN` → `bin/dsh.path` → PATH → 常见安装根 → 包内 `dsh/`，
所以即使 `dsh\` 空着，只要宿主机装了 DSH 也能找到 —— **但这就违背了"零配置"承诺**。

### 2. 只装了 1 个 agent ⬜
`npm-global\` 里只有 **gemini**。`agents.tsv` 声明了 19 个，其余 18 个在 TUI 里会显示「未安装」。
如果要演示效果，至少再装 2–3 个（claude / codex / qwen）才能体现「一屏看到全都能用」。

### 3. `workspace\` 和 `logs\` 是空的 ⬜
**注意：这不是「没跑过」的证据** —— 启动器根本不写 `logs\`，`workspace\` 也只在你在里面
启动 agent 时才会有东西。本轮完整跑过多次，两个目录依然为空，属正常。

### 4. TUI 渲染问题 ✅ 已修复（2026-10-27）
根因：`start.cmd` 用 `bash.exe launch.sh`，是**非登录** shell，不读
`/etc/profile.d/lang.sh` → `LANG/LC_ALL` 为空 → bash 的 `${#s}` 数**字节** →
`_dw()` 全部列宽算错 → 框宽不足 / 右边框碎裂 / 状态词折行。
当年"wt 下正常"是因为那次用了 `bash -lc`（登录 shell 会设 LANG）。

修法与验证见 `hub\README.md` 第 16 条与 `hub\tui\selftest.sh`。
已排除的方向（清屏失效、`tput cols`、HLINE、`clear`）确实都不是原因，**不必再查**。

## 四、已知的坑（照抄 hub/README.md 的复盘要点）

这些都是真金白银踩出来的，改代码前先看：

| # | 坑 | 结论 |
|---|---|---|
| 1 | `.cmd` 必须是**纯 ASCII + CRLF** | 中文会被按 GBK 解码、吞字符、解析器崩坏 |
| 2 | `(...)` 块内 `%VAR%` 在解析期就展开 | 必须用延迟展开 `!VAR!` |
| 3 | `subst` 残留会累积 | 启动时优先复用已指向本包的映射，否则取空闲盘符；退出要清 |
| 4 | 交互延迟 576 ms | 根因是每次按键 fork 数十子进程；改为启动时预生成字符串 → **0.47 ms** |
| 5 | 子 shell 风暴 | 清单变长后启动 6.5 s；改关联数组 + 全局变量 → 430 ms |
| 6 | 中文显示宽度 | 纯 bash 近似 `wc -L`，必须扣除「非 ASCII 但占 1 列」的字符（`·`、`—`、制表符、`✓●❯` 等） |
| 7 | 增量重绘 | 拼好的完整行再定位重绘，**光标只能定位到第 1 列**，否则前导空白重复 |
| 8 | 底边框多一个 `\n` | 光标越界导致上滚 1 行吃掉顶边框 |
| 9 | npm 垫片位置 | Windows 上 `.cmd` 垫片写在 **prefix 目录本身**，不是 `prefix\bin\`，所以 `npm-global` 要直接进 PATH |
| 10 | `cmd /c` 在 Git Bash 里 | MSYS 路径转换会把 `/c` 当路径，改从 PowerShell 调 |
| 11 | 非登录 bash 没有 UTF-8 locale | `${#s}` 数**字节** → 全部列宽错。**历史"画面错乱"的真根因**（详版：hub/README 第 16 条） |
| 12 | 算术里漏 `$` | `VIEW_H=n` 是赋字面量 `n`，靠外层同名 local 侥幸能算；换个作用域就 `unbound variable` |
| 13 | `trap … WINCH` | Windows 控制台不送 SIGWINCH，等于死代码；改空闲轮询尺寸 |
| 14 | 缩放瞬间尺寸是旧的 | 立刻重画会用旧尺寸画新窗口 → 整屏错位；要先 settle 再复核 |
| 15 | 退出时多一个 `\n` | 整屏恰好排满就上滚吃掉顶边框；改成清屏退出 |
| 16 | 擦凭据依赖 `subst` 映射 | 映射没了就**静默不擦**（安全相关）；清理段一律用 `%THIS_DIR%` |

**硬指标**：TUI 逐行 `wc -L` 必须全部等于 `CW + LEFT_PAD` —— 现在由
`bash hub/tui/selftest.sh` 自动断言（10 种尺寸 × 逐行 + 边框 + 行数）。
